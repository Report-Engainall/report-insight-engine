# MASTER COMMERCIAL REFERENCE — الأغبري
Status: CANONICAL DOMAIN REFERENCE

## 1. Commercial position
الأغبري is a Business Decision Operating System. It converts business data/documents into trusted action, not merely dashboards.

## 2. Commercial moat
- Evidence Passport
- Decision ROI Ledger
- Decision Coverage
- Money Recovery where evidence supports it
- Decision Playbooks
- Business Replay
- Benchmark Network with INSUFFICIENT SAMPLE protection
- Connector Memory
- Schema Drift Guard
- Evidence Agent Protocol / Aghbari Evidence MCP
- vertical packs without locking the platform to one sector
- Job-to-Demo / Proposal Compiler
- Commercial Proof

## 3. Value chain
Data -> Truth -> Evidence -> Signal -> Decision -> Approval -> Action -> Outcome -> Learning -> Benchmark

## 4. Buyer-visible value
Prioritize:
- time-to-first-trusted-answer
- time-to-first-decision
- evidence visibility
- money/risk opportunity visibility
- operational follow-through
- learning from outcomes
- benchmark confidence

Avoid feature-count marketing.

## 5. Product neutrality
The platform is domain-neutral. Individual sectors can have packs, but no sector becomes the product identity or unified-import UX.

## 6. Demo/proposal proof
Commercial surfaces should demonstrate:
source -> truth -> evidence -> decision -> action -> outcome

No demo may rely on fake business numbers presented as real.

## 7. Commercial quality bar
A commercially credible release should be:
- understandable in minutes
- visually coherent
- evidence-aware
- action-oriented
- mobile-capable
- safe under uncertainty
- demonstrable with real system state
