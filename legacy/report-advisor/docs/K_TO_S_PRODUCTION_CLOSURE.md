# K→S Production Closure

This document is the single cross-phase acceptance contract for the remaining lifecycle.

## K — Production Intelligence Runtime
Evidence must flow from durable execution through source/version/row lineage, canonical text, deterministic consolidation, bounded scenarios, portfolio ranking, outcome calibration and autonomy gating.

## L — Runtime Intelligence Cockpit
Live health, KPI/evidence graph, decision portfolio, materiality escalation, drift, approval workflow and autonomy eligibility must consume real K outputs; no synthetic evidence may certify a domain.

## M — Production Certification
Autonomy cannot be promoted until tenant isolation, storage, realtime, AI retrieval isolation, backup/restore, migration parity, artifact integrity, rollback and security evidence are current and passing.

## N — End-to-End Certification
A real source must traverse discovery → fingerprint → extraction → canonicalization → validation → governed import → business state → analytics → decision → approval → execution → outcome → calibration → audit.

## O — Scale & Performance
Validate representative small/medium/large datasets, concurrent analyses, memory pressure, cache behavior, slow networks, reconnects and P95/P99 budgets. Performance failures block release when they violate declared budgets.

## P — Product/UX Closure
Mobile/RTL/PWA, loading/error/empty/offline states, streaming stability, import/report workflows, evidence drill-down, executive cockpit, notifications and accessibility must be runtime verified.

## Q — Data & AI Hardening
Arabic/English normalization, units/currency/date handling, semantic mapping, product families, alternatives, duplicate/business-key handling, anomaly detection and evidence-bound AI must remain deterministic and tenant-scoped where truth is numeric.

## R — Final Release
Freeze architecture/schema/API/contracts, execute the full matrix, certify production, verify rollback, produce signed release evidence, deploy and smoke-test.

## S — Post-release Trust
Monitoring, error/performance regression, calibration, drift, security maintenance, backup/DR drills and controlled releases remain permanently active.

## Non-negotiable blockers
- cross-tenant access or retrieval;
- client-only entitlement enforcement;
- non-idempotent billing webhooks;
- workers without tenant context/lease;
- AI retrieval without tenant namespace;
- raw-file access from analytics/forecast/recommendation layers;
- fabricated extraction or unsupported numeric claims;
- autonomy without current evidence, confidence, risk budget and rollback capability.

The lifecycle is complete only when implementation, integration, runtime evidence and certification agree. Contract existence alone never marks a phase complete.
