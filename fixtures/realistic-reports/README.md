# Realistic Report Fixtures — Report-Advisor / الأغبري

هذا المجلد مخصص لملفات اختبار حقيقية الشكل لمسار الاستيراد الكانوني.

الملفات المقترحة:
- sales.xlsx
- purchases.csv
- inventory.csv
- receivables.xlsx
- structured-arabic-report.pdf
- scanned-arabic-report.pdf
- mixed-report.xlsx
- low-quality.csv
- multi-currency.csv

ارفع هنا فقط بيانات منزوعة الحساسية. لا ترفع كلمات مرور أو رموز وصول أو بيانات عملاء حقيقية.

الاختبار المطلوب لكل ملف:
Upload → Detection → Extraction → Understanding → Quality → Trust → Review → Canonical Commit → Analysis → Evidence → Signal → Decision → Work → Outcome/Learning → Benchmark

لا يعتبر الاختبار ناجحًا بمجرد رفع الملف؛ يجب إثبات الحالة الكانونية وسلسلة الدليل.
