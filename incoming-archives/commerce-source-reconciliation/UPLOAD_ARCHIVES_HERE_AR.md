# مكان رفع أرشيفات مشاريع متجر الأغبري — اقرأ هذا أولًا

هذا هو مجلد الاستقبال المعتمد لأرشيفات ZIP الإضافية:
https://github.com/Report-Engainall/report-insight-engine/tree/main/incoming-archives/commerce-source-reconciliation

## إذا كان ملف ZIP حجمه 25 MB أو أقل
1. افتح رابط المجلد أعلاه.
2. اضغط **Add file** ثم **Upload files**.
3. اسحب ملف ZIP أو اختره من جهازك.
4. اضغط **Commit changes** على فرع `main`.
5. كرّر ذلك لكل ملف مضغوط.

## إذا كان ملف ZIP أكبر من 25 MB (الطريقة المناسبة للأرشيفات الكبيرة)
استخدم نموذج رفع مرفقات الإصدار بدلًا من رفع الملف إلى قائمة ملفات المستودع:
https://github.com/Report-Engainall/report-insight-engine/releases/new?tag=commerce-source-intake-2026-10-16

1. اكتب عنوان الإصدار: `Aghbari Commerce — Incoming Project Archives`.
2. أرفق ملفات ZIP المطلوبة في قسم **Attach binaries by dropping them here or selecting them**.
3. انشر الإصدار (**Publish release**) حتى تبدأ عملية الجمع والمصالحة تلقائيًا.
4. لا تحذف الإصدار أو الأصول بعد الرفع؛ ستُستخدم أسماؤها ومحتوياتها لإعادة بناء الحزمة المرجعية.

## المطلوب رفعه
- أرشيف المشروع الذي يحتوي على 7 مشاريع.
- الأرشيف المضغوط الآخر الذي يحتوي على عدة مشاريع.
- ارفع كل ملف كما هو، ولا تفك ضغطه ولا تعِد تسميته.

## تنبيه
الملف الصغير الموجود حاليًا باسم `AGHBARI_COMMERCE_UNIFIED_SOURCE_PACKAGE (1).zip` هو جرد/بيانات وصفية وليس أرشيف الكود الكامل. الحزمة الحالية لقطة أساس وليست نتيجة المصالحة النهائية. بعد استلام أرشيفاتك ستُعاد عملية الفحص وتُنتج حزمة موحّدة جديدة مع جرد وفروق وبصمات سلامة.

**لا ترفع ملفات .env أو مفاتيح API أو كلمات المرور أو بيانات اعتماد حساسة.**
