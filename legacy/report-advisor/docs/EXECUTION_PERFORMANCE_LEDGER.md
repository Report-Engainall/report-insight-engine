This ledger measures execution strategy quality. It is not a replacement for the Master Execution Index and does not certify runtime or production capabilities.

## Measurement policy

`REAL MEASURED DATA > ESTIMATE > NO CLAIM`.

When a numeric denominator or closure count is not objectively available, record `UNPROVEN`, `NOT MEASURED`, or a qualitative effectiveness classification. Never manufacture precision.

## Strategy memory

### Effective / retained
- Parallel waiting windows.
- Dependency-aware scheduling.
- NEXT/NEXT+1/NEXT+2 consumption.
- Adversarial-first review and test-of-test.
- External blocker isolation.
- Exact-SHA evidence discipline.
- Automatic index synchronization.
- Layer separation between execution behavior, project truth, and strategy governance.
- Auditing workflow trigger paths immediately after adding new governed artifacts.

### Weak / avoid
- Treating commits, line counts, report size, index size, or test count as progress.
- Repeating audits without a new hypothesis or evidence target.
- Waiting for CI while leaving independent work untouched.
- Treating static PASS as runtime proof.
- Adding a governed artifact without binding its trigger path to the enforcement workflow.
