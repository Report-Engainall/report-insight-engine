# مجلد استقبال أرشيف المشاريع السبعة

هذا المجلد مخصص مؤقتًا لاستقبال ملف ZIP يحتوي على سبعة مشاريع إضافية بغرض الجرد والمقارنة وحفظ الملفات المتميزة والتعديلات ومصادرها.

## تعليمات الرفع
- افتح هذا المجلد ثم اختر **Add file → Upload files** لرفع الملف إذا كان حجمه ضمن حد GitHub لرفع الملفات من المتصفح.
- لا ترفع أي مفاتيح وصول أو كلمات مرور أو ملفات أسرار؛ احذفها من الأرشيف قبل الرفع.
- لا تفك ضغط المشاريع ولا تدمجها هنا. ارفع الأرشيف الأصلي كما هو بعد تنقيته من الأسرار.
- بعد اكتمال الرفع، أرسل رابط الملف أو رابط المجلد في المحادثة.

## تنبيه الحجم والخصوصية
هذا المستودع **خاص**، والأرشيف المرفوع داخله سيكون متاحًا لأصحاب صلاحية الوصول إلى المستودع فقط. رفع الملفات عبر واجهة GitHub للملفات العادية له حد حجمي؛ إذا تجاوز ملف ZIP الحد، فلا تحاول إضافته كملف Git عادي، وأرسل حجم الملف لنختار طريقة استلام مناسبة.
